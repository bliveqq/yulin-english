# 雨林英语云端资料部署包

此目录已经准备好发布文件，但尚未上传、开通域名或产生云服务费用。

## 包含什么

- `public/manifest.json`：安卓应用读取的资料目录，包含大小、SHA-256 校验值和文件对应关系。
- `public/files/`：2,498 份资料的发布文件，约 4.21 GB。文件按校验值命名，避免中文 URL 和重名问题。
- 3 份 WMA、1 份 AMR、1 份 WAV 已转为 MP3；其余 MP3 保留原始字节。转换没有变速、变调、降噪或替换配音。
- `build-report.json`：处理结果。原始文件未改动。

## 方法一：对象存储（OSS、COS 或其他支持 HTTPS 的存储）

1. 创建用于资料下载的存储空间，设置 HTTPS 访问域名和文件公开读取权限。不要提供公开写入权限。
2. 将 `public` 中的内容按原结构上传到一个目录，例如 `english/`。上传后应存在 `https://你的域名/english/manifest.json` 和同目录下的 `files/`。
3. 存储服务应支持 HTTP Range（断点续传）；如果只返回完整文件，应用会从头下载。不要设置强制跳转到登录页或其他域名的链接。
4. 在应用“教学工具 → 联网下载与发音”中输入 `https://你的域名/english/`，保存后刷新云端目录。
5. 在“题库 → 全国整卷与听力”打开资料，选择“下载到本机”。完成后可以离线打开或播放。

应用使用安卓原生 HTTPS 下载，不依赖浏览器跨域配置。不需要把云账户密钥填写到应用里。当前版本只支持通过 HTTPS 直接读取的静态文件；网盘分享页面、需要网页登录的链接、临时签名 URL 不适用。

## 方法二：自有服务器

部署一个启用有效 HTTPS 证书的静态文件服务，将根目录指向 `public`。保留 Range、Content-Length 和正确的 Content-Type。提供了 Nginx 配置片段 `nginx-location.conf`，在已有 HTTPS 虚拟主机中引用并按实际路径修改。

不要把系统根目录或源代码目录作为下载根目录。无需数据库、Python 服务或 DeepSeek 密钥。

## 上线验证

可以在部署后运行：

```sh
python3 verify_host.py https://你的域名/english/
```

该检查只获取目录和一个文件的前 1 KB，核对 HTTPS、路径及服务器响应，不上传文件。最终请在安卓设备上验证下载、暂停续传、飞行模式下打开、听力暂停/拖动/倍速。

## 更新、缓存和限制

- 先上传新的 `files/` 文件，最后更新 `manifest.json`；目录缓存建议不超过 5 分钟，哈希文件可长期缓存。
- 当前目录中的 ID 对应本版 APK 的资料索引。可以替换同 ID 的音频转换版本、修正原文件，但增加全新资料条目还需要更新 APK 的本地索引。
- 单文件限制 512 MB，一次下载一个文件；暂停或网络中断后可继续。应用校验下载内容后才允许打开。
- 不支持用户账号、付费权限、私有签名链接或跨设备学习进度同步。
- 服务器出网流量可能收费，由所选云服务的套餐决定。
- 下载保存于应用内部。卸载或清除数据会移除下载，备份 JSON 不含音频和原卷文件。
