# 雨林英语独立资料服务器

这是可部署在自有 Linux 服务器上的雨林英语资料下载服务，不依赖 OSS 或 Sites。当前只完成程序和部署准备，没有购买或开通云服务器，也没有公网服务地址。

## 已实现

- 兼容现有雨林英语 1.3.0 APK，无需重新安装即可改用自己的服务器。
- `/english/manifest.json` 提供资料目录；`/english/files/…` 提供原卷和音频。
- 支持 HTTP Range 断点续传、音频分段读取、文件长度和缓存信息。
- `/healthz` 检查服务是否响应，`/api/status` 提供已准备的资料数量与版本；后者不是实时磁盘完整性扫描。
- HTTPS 证书由 Caddy 管理，证书数据持久保存。
- 仅允许读取公开的发布资料，禁止网页上传和目录浏览。维护资料通过服务器 SSH/SFTP 完成。

尚不包括用户登录、跨设备进度同步、在线管理后台或服务端 AI 生成。现有应用的 AI 连接方式保持原样；未把 DeepSeek 密钥写入服务端或 APK。

## 上线前需准备

1. 一台长期运行的 Linux 主机，具有公网访问能力和足够的存储、出网带宽。
2. 当前资料约 4.21 GB。部署空间还需覆盖系统、容器和后续资料增长。
3. 可用于受信任 HTTPS 的访问地址。标准部署使用域名指向服务器，开放 TCP 80、443；UDP 443 为可选的 HTTP/3。不要将本机 `127.0.0.1` 填进学生设备。
4. 安装 Docker Engine、Docker Compose。检查前述资源费用后再开通，不需要继续上传 OSS。
5. 中国内地部署的域名及应用相关手续需按服务商要求办理。

## 目录放置

将本目录上传到服务器，例如 `/opt/yulin-server/`。把原部署资料目录 `rainforest-android/cloud-deploy/public/` 的内容放到 `/opt/yulin-server/data/`，形成：

```
/opt/yulin-server/
  Caddyfile
  compose.yaml
  .env
  start.sh
  prepare.py
  site/
  data/
    manifest.json
    files/
```

不要上传整个开发工作区。资料包约 4.21 GB，启动程序压缩包不重复包含这些文件。

## 配置与启动

复制 `.env.example` 为 `.env`。填写实际域名和资料路径：

```
SITE_ADDRESS=实际下载域名
LIBRARY_DIR=./data
```

在服务器项目目录运行（需 Python 3.11 或以上）：

```
python3 prepare.py --library ./data
sh start.sh
```

准备工具会逐个核验资料大小和 SHA-256；成功后生成状态文件。启动脚本验证配置后运行服务。首次启动需要下载 Caddy 容器镜像并签发证书；必须保证 DNS 和端口已就绪。没有公网地址时仅完成本地验证，不能视为上线成功。

查看状态和日志：

```
docker compose ps
docker compose logs --tail=100
```

## 接入安卓应用

先访问 `https://实际下载域名/healthz`，确认返回 ok。

在应用“教学工具 → 联网下载与发音”中填写：

```
https://实际下载域名/english/
```

刷新目录后在题库下载资料。再用一份非空音频检查暂停、继续下载和离线播放。服务器不会改善录音原始音质，也不替代系统的单词朗读引擎。

## 更新和备份

- 新资料先上传到 `data/files/`；全部完成后最后替换 `manifest.json`。目录采用临时文件上传再重命名，避免读到半个文件。
- 文件使用内容校验值命名，不覆盖同名文件内容。
- 修改目录后重新运行 prepare.py 验证和刷新状态。不需要重启服务。
- 当前 APK 内置的资料索引仍限制可见条目；增加新试卷需要同步更新应用索引。
- 备份 `data/`、配置文件及 Caddy 的命名卷。不要用 `docker compose down -v` 删除证书卷。
- 该下载服务公开提供资料，任何获得链接的人均可下载，下载流量由服务器账户承担。

## 技术依据

https://caddyserver.com/docs/caddyfile/directives/file_server
https://caddyserver.com/docs/running

公开访问验证命令（不需要账户密钥）：

```
python3 check_online.py https://实际下载域名
```

它会检查 HTTPS、目录、最小文件的完整校验值和实际 Range 响应，不会下载整套资料。
